| `Gebaeude_A_EG.pdf` | Gebäude A, Erdgeschoss, 1:250, A3 hoch, **gedreht** (Norden links) | Bezug Campusplan, Passpunkte «Ecke Gebäude A (SW)» und «Ecke NO» → 1 px ≈ 0.0318 m, Drehung −90° |
